Data-Availability Statement checker

Choose a paper PDF to look for artifact-availability sections, extract DOI links, and test their HTTP responses.

The PDF is processed only in your browser, never uploaded. PDF.js loads from a CDN. If link checks are enabled, DOI requests go to doi.org, redirected repositories, and DataCite (for descriptive metadata), revealing those identifiers and your IP address. No proxy or server is used.

The URL is saved in this page’s address and reloaded on refresh. Remote PDFs must allow browser access (CORS); otherwise download and upload the file.
